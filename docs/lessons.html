Lessons

What this project taught. Newest first.

From this project

  • Check that the inputs carry information before tuning the learner. v1 spent its effort on rewards, learning rates and advantage clipping, while the lidar read 0 on every ray. One print of an observation would have shown it.
  • A dictionary key that never exists fails silently. info.get("finished_track", False) and getattr(wheel, "ground_contact", True) both return the default forever. Test that a bonus can be paid and that a penalty can fire.
  • Profile before porting. 99% of a CarRacing step was drawing an image the agent never used; turning it off gave ~90× on the env, more than any language port could.
  • Train on the metric. v1's shaped return (best 501) said nothing about the real score (−43). v2 trains on CarRacing's own reward and reports only that.
  • Keep the reference as the judge. The fast env is checked against the reference, bit for bit, in the test suite; the goal check runs in the reference.
  • Best-of-many flatters. The best validation score is the maximum of many checks on 16 tracks; the goal is measured once, on 100 other tracks.
